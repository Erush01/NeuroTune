# P2 Independent-Test Source and License Research

**Reviewed:** 24 November 2026  
**Decision:** No reviewed public dataset is currently ready for the frozen P2 test. The user clarified this is a course assignment rather than a commercial product and said further research of this kind is unnecessary; P2 source selection is deferred.  
**Data boundary:** No corpus was downloaded; no sample rows, labels, or APIs were accessed. This review covers public owner documentation, dataset metadata, and terms only.

## Requirements from the frozen P2 protocol

P2 needs a full-catalog track-retrieval test with artists disjoint from NeuroTune's development cohort, independent relevance judgments, and a permissible path for the intended product use. The test labels must not affect training, preprocessing, negative selection, checkpoint selection, or thresholds. The primary comparison is frozen D4 neural versus D4-matched cosine on identical queries and candidates; acceptance requires an absolute macro-query NDCG@10 lift of at least +0.01 and a paired 95% artist-cluster bootstrap lower bound above zero. The full protocol is in `2026-11-24-neurotune-p2-independent-test-protocol.md`.

## Candidate assessment

| Candidate | What official sources establish | Fit and constraints | Decision |
|---|---|---|---|
| **MIREX/SAS Semantic Artist Similarity** | The [UPF Music Technology Group owner page](https://www.upf.edu/web/mtg/semantic-similarity) and [Zenodo record](https://zenodo.org/records/1291810) describe a 268-artist set mapped to MIREX similarity judgments and a separate 2,336-artist set whose similarity lists come from the Last.fm API. Artist identities are MusicBrainz IDs. The MIREX-mapped set has at least ten related artists for only 188 of 268 artists. | The labels are artist-level rather than track-level, so they do not directly evaluate the current track-retrieval task. The owner page says the dataset is for internal non-commercial use only and prohibits redistribution, public communication, or modification; the scope for a published evaluation requires written clarification. The 2,336-artist portion reuses Last.fm similarity labels and is not independent of the development label family. The official MIREX task page could not be retrieved because its TLS certificate was expired; no separate rights claim is inferred from that page. | **Do not use as the P2 track test.** The MIREX-mapped subset is distinct from the Last.fm API labels but still has the track-level mismatch and restrictive terms; consider it only after written rights-holder clarification for a different artist-level, non-commercial study. The Last.fm API subset is not an independent test. |
| **MagnaTagATune / TagATune** | The [TagATune owner site](https://tagatune.org/) says the game collects music annotations including similarity comparisons. Its [dataset details and license page](https://tagatune.org/details) documents human annotations, artist-plus-album sharding, and a CC BY-NC-SA 3.0 license for the dataset; the audio excerpts are separately licensed by their artists under similar terms. | This is a plausible research lead for human track-level judgments, but the current owner pages reviewed do not establish a sufficiently clear stable track/artist-ID mapping or the exact downloadable similarity-judgment coverage for P2. The non-commercial/share-alike terms are incompatible with assuming product use or redistribution is permitted. | **Not ready for selection.** Could be reconsidered for a non-commercial research-only evaluation after schema/coverage and rights are clarified. |
| **MSD Last.fm similarity data** | The [official MSD Last.fm page](http://millionsongdataset.com/lastfm/) says the collection contains song-level similarities obtained with Last.fm's `getSimilar` API, provides MSD track IDs and a train/test split, and is “research only, strictly non-commercial.” It also warns of song/track matching errors and duplicates. The [Last.fm API terms](https://www.last.fm/api/tos) limit use to non-commercial purposes unless a separate commercial-use agreement is obtained. | This is the same Last.fm-derived similarity label family used in NeuroTune development; its split does not make it an independent label source. | **Reject for P2.** It fails label independence and has explicit non-commercial restrictions. |
| **Free Music Archive (FMA)** | The [first-party FMA repository](https://github.com/mdeff/fma/blob/master/README.md) documents track IDs, artist metadata, tags, genres, and play counts. It says metadata is CC BY 4.0; the audio license is chosen by each artist, and the dataset is intended for research. | The owner documentation does not establish pairwise similarity or relevance judgments. Track-level audio rights vary, so metadata licensing alone does not grant rights to use the audio in a product. | **Not a relevance test by itself.** It could be investigated as a catalog for newly collected judgments only after per-track rights and artist/track disjointness are verified. |

## Conclusion and recommendation

None of these sources meets all P2 requirements as currently documented. Last.fm MSD is not label-independent. FMA does not provide the required relevance judgments. MIREX/SAS is artist-level and internally non-commercial; only its MIREX-mapped portion is distinct from the Last.fm API similarity labels, but it still does not match the track-level task and its use terms need written clarification. MagnaTagATune is the closest public human-judgment lead, but its rights are non-commercial/share-alike and its public identity/coverage documentation is not yet sufficient for the frozen test.

For any future product-readiness claim, the most defensible route appears to be an independently licensed track cohort plus newly collected human relevance judgments, with consent and data-use terms reviewed before collection. If a future academic/non-commercial evaluation is requested, follow-up could instead ask the relevant MIREX/SAS or TagATune rights holders for written permission and a schema/coverage description. No such follow-up is planned for the current course assignment. Neither route should open labels until the artist/track overlap, judgment policy, label density, licenses, and frozen acceptance rule have passed the P2 preflight.
