# M2 N0 Siamese Encoder Design

## Goal

Implement and run one small shared-weight Siamese encoder on the current 10K MSD
subset, as an exploratory prototype only. The audited feature catalog has 939
tracks and the artist-disjoint split has 416/6/11 observed positive edges in
train/validation/test. This is too little test relevance for a defensible gain
claim, but supports a smoke-test of the training pipeline.

## Approved model

- Use the existing seed-684 artist-disjoint split. Only training-internal
  positive edges are training positives; do not train on validation/test edges
  or create cross-partition pairs.
- Fit BPM scaling, 5,000-word smoothed TF-IDF, and genre categories from train
  IDs only. Preserve separate modality tensors for the neural branches.
- Shared encoder for both pair sides:
  - BPM: Linear(1, 8) + ReLU
  - Lyrics: Linear(5000, 32) + ReLU
  - Genre: Linear(train genre count, 16) + ReLU
  - Concatenate to 56, Linear(56, 64), L2-normalize to a 64-D embedding
- Pair loss: contrastive margin loss `y * D^2 + (1-y) * max(0, margin-D)^2`,
  where observed Last.fm edges are positives and sampled unobserved candidates
  are not treated as verified negatives.
- Fixed negative policy: one negative per positive per epoch; half sampled
  uniformly from all eligible within-training non-edges, half uniformly from
  eligible same-genre non-edges. Filter self-pairs, duplicates, and all known
  positive edges. Rejection-sample from partition IDs and genre groups; do not
  materialize all O(N^2) candidate pairs. Resample training negatives each
  epoch; validation negatives are fixed per seed. If the negative count is odd,
  use floor(count/2) same-genre negatives and assign the remaining negative to
  the random group.
- Fixed exploratory settings: Adam, learning rate 0.001, margin 1.0, batch size
  64, 50 epochs, seeds 684/685/686. No hyperparameter selection from test.
  Validation loss is recorded but does not select epochs; final fixed-epoch
  checkpoints are evaluated once on the test gallery.
- Record the actual train pair IDs for every epoch and the fixed validation
  pair IDs per seed. Include code hashes and runtime dependency versions with
  the experiment report.
- Test ranking remains within the 89-track held-out gallery, with the same
  observed test edges and metrics used by B0. Report three seed results and
  their simple mean/spread descriptively, without inferential claims.

## Alternatives considered

- A hand-written NumPy backpropagation loop was rejected: it duplicates
  autodifferentiation poorly and creates unnecessary numerical risk.
- Full-MSD expansion remains the preferred route for a credible evaluation, but
  it is outside this small-scope choice and requires a roughly 280 GB download.

## Risks and limits

- Only six validation and eleven test edges remain; validation curves and test
  retrieval are highly unstable.
- Unobserved pairs may be false negatives despite filtering known positives.
- The full MSD subset contains only 939 usable tracks; no claim of generalization
  beyond this catalog is warranted.
- The workspace has no Git repository. PyTorch CPU 2.15.0 is installed in
  `.venv` and pinned in `requirements.txt` after user approval.

## Decision status
